# AC Analysis Methods on STM32

## Overview

University project exploring AC signal analysis on STM32 microcontrollers using Embedded C. The work covers the Goertzel algorithm and single-point DFT/DTFT approaches for analysing a selected frequency component.

## Technical scope

- Implemented frequency-component analysis methods in C on STM32.
- Worked with STM32F303/F446 platforms.
- Examined embedded implementation of Goertzel and single-point DFT/DTFT methods.

**Tools:** Embedded C and STM32.

**Repository status:** Project summary only. Implementation, measurement configuration and confirmed comparative results can be added with the original project files.
